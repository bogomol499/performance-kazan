# Performance — кафе-сцена в Казани

Учебный проект для портфолио: сайт вымышленного кафе в Казани с меню, корзиной, программой вечеров и онлайн-бронью столов. Сайт можно установить на телефон как приложение.

**Открыть сайт:** https://bogomol499.github.io/performance-kazan/

![Превью](icons/og.png)

## Что умеет сайт

- **Анимации при прокрутке** (файлы `css/motion.css` и `js/motion.js`): элементы въезжают при появлении и уезжают, когда уходят с экрана; заголовок первого экрана разъезжается в стороны; бегущие строки ускоряются и меняют направление вместе с прокруткой; тарелки в меню крутятся; тёмная секция раскрывается из карточки; карта приближается; подвал выезжает из-под страницы.
- **Для мыши**: плавная прокрутка колёсиком, кнопки-магниты, карточки блюд наклоняются в 3D.
- **Занавес при загрузке.** Шторы с татарским орнаментом расходятся, буквы заголовка выезжают по очереди.
- **Прожектор на первом экране** двигается за курсором или пальцем.
- **Выдвижное меню** на весь экран и **корзина**, которая выезжает сбоку.
- **Меню с категориями**: плашка переключателя плавно скользит, карточки блюд появляются по очереди. Рисунки блюд нарисованы кодом в SVG.
- **Карточка блюда** выезжает снизу. На телефоне её можно смахнуть вниз пальцем.
- **Корзина**: блюдо «летит» в иконку корзины, количество можно менять, заказ сохраняется после перезагрузки.
- **Программа недели**: на компьютере карточки едут вбок при прокрутке страницы, на телефоне листаются пальцем. Кнопка на карточке сама подставляет нужный день и время в форму брони.
- **Бронь стола**: выбор даты, времени, числа гостей и зоны; проверка полей, маска телефона, список своих броней с отменой.
- **Статус «открыто/закрыто»** считается по казанскому времени.
- **Приложение (PWA)**: иконка на экране телефона, запуск без адресной строки, работа без интернета.
- Адаптивная вёрстка под телефон и компьютер, управление с клавиатуры, учёт настройки «уменьшить движение».

## Технологии

HTML, CSS, JavaScript без библиотек и фреймворков. Service Worker, Web App Manifest, Intersection Observer, Web Animations API, localStorage.

## Структура

```
index.html            страница
css/style.css         стили и анимации
js/app.js             логика: меню, корзина, бронь
css/motion.css        анимации при прокрутке
js/motion.js          анимации при прокрутке, курсор, плавная прокрутка
manifest.webmanifest  настройки приложения
sw.js                 работа без интернета
icons/                иконки и картинка для превью ссылки
```

## Как запустить у себя

Откройте `index.html` в браузере. Для проверки установки как приложения нужен адрес `https://`, поэтому удобнее смотреть уже опубликованную версию на GitHub Pages (инструкция в файле `ИНСТРУКЦИЯ.md`).
