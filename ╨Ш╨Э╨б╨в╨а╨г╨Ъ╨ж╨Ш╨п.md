# Как выложить сайт на GitHub и получить ссылку

Сайт будет бесплатно работать на **GitHub Pages**. Сервер не нужен: GitHub сам раздаёт файлы. В конце у вас будет ссылка вида:

**https://bogomol499.github.io/performance-kazan/**

Всё делается в браузере, терминал не нужен. Займёт около 10 минут.

---

## Шаг 1. Распакуйте архив

1. Найдите файл `performance-kazan.zip`.
2. Нажмите на него правой кнопкой мыши и выберите **«Извлечь все…»**, затем **«Извлечь»**.
3. Откройте получившуюся папку `performance-kazan`. Внутри должны быть:
   `index.html`, `README.md`, `manifest.webmanifest`, `sw.js`, `ИНСТРУКЦИЯ.md` и папки `css`, `js`, `icons`.

## Шаг 2. Создайте новый репозиторий

1. Зайдите на https://github.com и войдите в свой аккаунт **bogomol499**.
2. Справа вверху нажмите **«+»**, затем **«New repository»**.
3. В поле **Repository name** напишите: `performance-kazan`
   (именно так, маленькими буквами, через дефис: это название станет частью ссылки).
4. В **Description** можно написать: `Сайт кафе-сцены в Казани. Учебный проект для портфолио`.
5. Выберите **Public** (публичный). Для бесплатного GitHub Pages это обязательно.
6. Галочки ниже (README, .gitignore, license) **не ставьте**.
7. Нажмите зелёную кнопку **«Create repository»**.

## Шаг 3. Загрузите файлы

1. На открывшейся странице найдите ссылку **«uploading an existing file»** и нажмите на неё.
2. Откройте папку `performance-kazan` на компьютере.
3. Выделите **всё содержимое папки** (нажмите `Ctrl + A`) и перетащите мышкой в окно браузера, в область «Drag files here».
   Важно: перетаскивайте именно содержимое папки, а не саму папку `performance-kazan`. Иначе ссылка получится длиннее и сайт может не открыться.
4. Подождите, пока внизу появится список файлов. Проверьте, что там есть `css/style.css`, `js/app.js` и файлы из `icons/`.
5. Внизу в поле **Commit changes** можно написать `Первая версия сайта`.
6. Нажмите зелёную кнопку **«Commit changes»**.

## Шаг 4. Включите GitHub Pages

1. В репозитории откройте вкладку **Settings** (шестерёнка вверху).
2. В меню слева выберите **Pages**.
3. В разделе **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: выберите `main`, рядом папку `/ (root)`
4. Нажмите **Save**.
5. Подождите 1–3 минуты и обновите страницу. Вверху появится надпись **«Your site is live at…»** со ссылкой. Это и есть адрес вашего сайта.

## Шаг 5. Проверьте сайт

1. Откройте ссылку на компьютере: должен появиться красный занавес, который расходится в стороны.
2. Откройте ту же ссылку на телефоне.
3. Установите как приложение:
   - **iPhone (Safari):** кнопка «Поделиться» внизу, затем «На экран Домой», затем «Добавить».
   - **Android (Chrome):** меню ⋮ справа вверху, затем «Установить приложение».
   На сайте есть кнопка «Установить приложение» в меню и внизу страницы: она покажет те же подсказки.

## Шаг 6. Оформите репозиторий для портфолио

1. На главной странице репозитория справа, в блоке **About**, нажмите шестерёнку.
2. В поле **Website** поставьте галочку **«Use your GitHub Pages website»**.
3. В **Topics** добавьте: `html`, `css`, `javascript`, `pwa`, `portfolio`.
4. Нажмите **Save changes**. Теперь ссылка на сайт видна прямо на странице проекта.
5. Чтобы проект был виден сразу на вашем профиле: откройте свой профиль, нажмите **Customize your pins** и отметьте `performance-kazan`.

---

## Как обновлять сайт потом

1. Измените нужный файл у себя на компьютере.
2. Откройте файл `sw.js` и поменяйте версию в первой строке кода, например
   `const VERSION = 'performance-v1';` на `const VERSION = 'performance-v2';`.
   Без этого у тех, кто установил приложение, может остаться старая версия.
3. В репозитории нажмите **Add file**, затем **Upload files**, перетащите изменённые файлы (с той же структурой папок) и нажмите **Commit changes**.
4. Через 1–2 минуты изменения появятся на сайте. Если не видно, обновите страницу с `Ctrl + F5`.

## Обновление с прошлой версии сайта

В новой версии появились новые файлы: `about.html`, `admin.html`, `css/features.css`, `css/pages.css` и несколько файлов в папке `js`. Поэтому загрузите **всё содержимое** новой папки, как в шаге 3: **Add file → Upload files**, выделить всё (`Ctrl + A`), перетащить, **Commit changes**. Старые файлы с такими же именами заменятся сами.

Проверьте после загрузки:
- главная: https://bogomol499.github.io/performance-kazan/
- «О нас»: https://bogomol499.github.io/performance-kazan/about.html
- админка: https://bogomol499.github.io/performance-kazan/admin.html (пароль `performance`)

## Если что-то не работает

| Что случилось | Что сделать |
|---|---|
| Ссылка показывает ошибку 404 | Подождите ещё пару минут. Проверьте, что `index.html` лежит в корне репозитория, а не внутри папки `performance-kazan`. |
| Сайт без стилей, всё белое и в столбик | Не загрузились папки `css` и `js`. Загрузите их ещё раз через **Upload files**. |
| Нет кнопки установки на Android | Откройте сайт именно в Chrome и подождите несколько секунд. На iPhone установка только через Safari. |
| Хочу изменить блюда или цены | Всё содержимое в файле `js/data.js`: меню `MENU`, программа `EVENTS`, вопросы `FAQ`. У каждого текста русский (`ru`) и татарский (`tt`) вариант. Цены можно менять и в админке, но только для своего браузера. |
